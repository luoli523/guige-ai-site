## 这个站是什么

**鬼哥的 AI 行业动态** 是一个每日更新的 AI 深读站：一天一篇，把当天 AI 行业与技术领域值得关注的事情，
挑出两到四条主线做深度梳理，而不是流水账式地罗列标题。

每篇的结构固定：**执行摘要 → 主线深度解析 → 次要动态 → 来源与延伸阅读 → 今日行动建议**。
主线部分会讲清背景、机制与能力边界、证据、以及对工程和学习的实际启示。

它首先是我自己的信息入口 —— 替代每天在信息流里反复刷。同时它是公开的，
如果你在跟着我的学习路径走，这里就是我每天在看的东西。

## 内容是怎么来的

**本站内容由自动化流水线生成，没有逐条人工核实。**

1. **采集** — 后台 bot 每日扫过下列信源，交叉核实同一事件的多个来源
2. **梳理** — LLM 去重、归类、按主线组织成结构一致的深读报告
3. **发布** — 提交到本仓库，GitHub Actions 构建并部署到 GitHub Pages

所以：**请以每条后面的原始信源链接为准。** 摘要可能有偏差，日期可能有误差，遇到重要判断请点回原文。

## 信源

每日候选至少覆盖以下五类，不只依赖单一渠道：

| 类型 | 来源 |
|---|---|
| 社交媒体 | X.com —— Following 与公开的 AI 技术/产品讨论 |
| 代码仓库 | GitHub —— 重要 Release、热门仓库、关键 org 的新仓与大更新 |
| 模型社区 | Hugging Face —— Trending 模型/数据集、官方 org 的新模型卡 |
| 官方一手 | OpenAI、Anthropic、Google DeepMind、Meta AI、Microsoft Research 的 Blog 与研究页 |
| 论文 | arXiv 的 cs.AI / cs.CL / cs.LG 高热或大厂挂名预印本 |

每篇文章头部的「信源」一行，列的是**当天实际用到**的渠道，不是上面这张全集表。

## 证据标注

正文里的每条关键信息都带一个可信度标签，方便你判断该信几分：

| 标签 | 含义 |
|---|---|
| **FACT** | 可用官方文档、可核验源或研究者一作交叉确认 |
| **官方自报** | 厂商自己的评测或宣传数字，引用时必须标明出处 |
| **待核** | 二手转述、未独立核验、或厂商联名演示缺原始帖 |

## 筛选标准

一天只留真正有信息量的几条，判断依据：

- **有实质变化** — 发布了、开放了、涨价了、停服了；而不是「某某表示」「据传」
- **可验证** — 有官方公告、有论文、有代码；而不是二手传闻
- **对做事的人有用** — 影响到实际的技术选型、成本或可用性
- **不重复** — 同一件事只记一次，后续进展合并进原条目

还有三条硬规则：**不确定的信息宁可标「待核」或删掉，也不写成确定事实**；
**不编造日期、金额、benchmark、用户量**；**当天内容不够格就不发**，宁缺毋滥。

想看完整的产出规范，直接读 [docs/BOT.md](https://github.com/luoli523/guige-ai-site/blob/main/docs/BOT.md)——
那份文档同时也是 bot 的 system prompt。
