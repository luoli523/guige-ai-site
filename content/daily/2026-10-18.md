## 一分钟速览

- 本期覆盖 10 月 15 日早上到 10 月 18 日早上约 3 天（Asia/Singapore）。
- Anthropic 让 Claude 在一个自动评分器的闭环里自己设计量子电路，8 个任务都超过了已发表的最好方案，其中一个椭圆曲线电路门数降到原来的 1/17。
- 开发者工具 OpenCode 的旧版 Console 被入侵，约 1.4% 用户存在里面的 OpenAI、Anthropic、Google API key 可能泄露，官方把这件事定性为一次大规模蒸馏攻击。
- 商务部、科技部公告拟把 23 项 AI 技术（含大模型、智能体）列入出口禁限目录，征求意见到 11 月 15 日，开源和已公开发表的技术不在管制范围内。
- 三天里出了四个大号开放权重模型：Meta Muse Spark Open、Reflection Beam、NVIDIA Nemotron 3.5，以及 DeepSeek V4.1-Flash-1017。DeepSeek 还开始单独售卖自家的搜索 API。

## 执行摘要

- 只要结果能被程序自动核对，AI 已经能自己做出新的科研成果。Claude 设计的量子电路和 Athanor 的自主后训练实验用的都是「AI 提方案、评测器打分」这一套。
- 蒸馏之争开始让开发者自己掏钱：攻击者偷走聚合工具里存的 API key，拿受害者的额度去调用前沿模型。用过托管 key 服务的人应该马上轮换 key。
- 中国第一次把大模型和智能体写进技术出口管制目录。影响最大的是闭源技术的海外转让、授权和股权变更，开源基本不受影响。
- 美国开放权重模型集中发布，但按 Artificial Analysis 的分数，Muse Spark Open 的 38.9 仍低于中国头部开源模型（MiMo-V2.6-Pro 是 46.3）。许可证的差别比分数更值得看。
- Anthropic 公开了多份一手数据：Claude 写了 Claude Code 约 90% 的代码；公司初级技术岗的招聘占比从 27% 降到 9%；METR 的研究人员拿到了接近员工级别的内部访问权限。

## 大厂与学术界动态

### 主线：Claude 自主设计量子电路，AI 科研先在「能自动验证」的问题上交出成绩

本期最硬的研究结果是：AI 在一个有明确对错的科学问题上，基本独立地超过了人类已发表的最好方案。Anthropic 10 月 17 日 01:29（Asia/Singapore）发布 [Designing more efficient quantum circuits with Claude](https://www.anthropic.com/research/designing-efficient-quantum-circuits)。研究人员用一段自然语言描述了 8 个量子电路要算什么，覆盖化学、优化、量子模拟、数论和数值计算，再配一个评测程序。评测程序先检查电路算得对不对，再按「qubit 数 × 门数」打分，这个分数可以粗略看作电路的运行成本。Claude Mythos 5 在这个闭环里写 Python 实现、拿到分数、再改进，轮与轮之间没有人参与。官方称，8 个任务里 Claude 都找到了优于已发表最好方案的新设计，多数同时省下 qubit 和门数。

可以把它想成一场有自动阅卷机的考试。题目是把一个已知功能的电路做得更省，而在这类问题上，每个输入都有唯一确定的输出，普通电脑就能核对答案。所以 AI 可以大胆试错，错了马上就会被判出来。这也是它能连续跑很久的前提：椭圆曲线点加法这个任务，Claude 跑了 53 小时，人只写了开头一段说明，中途偶尔提醒它「想得更宽一点」。

最有分量的发现是一种新的模逆电路。模逆是椭圆曲线运算里最贵的一步，经典计算机常用 divsteps 算法来做，但量子电路的每一步都必须可逆，divsteps 每一轮选了哪个分支都得存下来，qubit 开销太大，过去一直没有实用的量子版本。Claude 的思路是不存分支记录，直接从每轮之后的数值反推出分支。它先证明了几条新的代数恒等式，推出解码公式，再做大规模数值验证，最后用 Lean（一种形式化证明工具）把这个结论形式化。在此基础上，它做出了一组在「存」和「算」之间取不同平衡的设计。其中一款和此前最小的设计相比，qubit 多 12%，门数少 17 倍。另一个任务是 DQI 优化算法里最贵的解码步骤，Claude 改用 Berlekamp-Massey 解码，门数大约降到原来的 1/12。配套论文 [arXiv 2610.22367](https://arxiv.org/abs/2610.22367) 由 Harvard 的 Yelin、Lukin（同时任职 QuEra）和 Anthropic 研究员合著，论文自述 8 个任务里有 7 个的 Toffoli 门数和 qubit 数都明显低于 SOTA，具体降幅要看正文表格。

这件事和密码学直接相关。椭圆曲线点加法是用量子计算机破解椭圆曲线密码的核心步骤，这一步越便宜，「量子计算机能破解现有密码」的时间表就越靠前，做后量子密码迁移规划的人需要留意。前一天 Google Quantum AI 在 [Science 上的成果](https://blog.google/innovation-and-ai/models-and-research/quantum-computing/magic-state-cultivation-quantum-computing/) 从硬件这一侧推进：他们在 Willow 处理器上第一次实验证明 magic state cultivation（魔术态培育）可行。魔术态是通用容错量子计算必需、又极其昂贵的资源，官方称这次误差比不做培育降低约 40 倍，T 态逻辑保真度达到 99.99%。一边算法和电路在变省，一边硬件瓶颈在被打开，两件事都在把可用量子计算的时间往前拉。

同一套模式也出现在 AI 研究本身。ByteDance 等机构的 [Athanor（arXiv 2610.21055）](https://arxiv.org/abs/2610.21055) 让 4 个 Claude Opus 5.5 agent 各用一台 8 卡节点，跑了 104 小时，不给任何研究建议，自主完成 Qwen3-4B-Base 的后训练。论文自述开发集分数从 15.9 升到 67.3，agent 看不到的 held-out 集从 9.2 升到 48.2，略高于官方 Qwen3-4B-Instruct-2507 的 66.5 和 47.9。

它的边界也要看清。这种做法只适用于「能写成代码、能自动判对错、有明确成本函数」的问题。没有评测器的开放问题，比如提出新的物理理论，并不在这次的能力范围里。Anthropic 也写到 Claude 起初偏保守，总爱回到熟悉的方案，要靠「强制并行探索几种方案」和人偶尔的提示才肯冒险。对科研人员来说，可以直接借鉴的是这套组织方式：先把自己领域里能自动验证的子问题找出来，写好评测器，再交给 agent 去搜索。

**深入学习建议**

- 先读 [Anthropic 博客原文](https://www.anthropic.com/research/designing-efficient-quantum-circuits)，重点看图 1 的闭环设计，以及 divsteps 解码那一节；再看 [论文 2610.22367](https://arxiv.org/abs/2610.22367) 的表格，核对每个任务的具体降幅。
- 关心量子硬件的读者，接着读 [Google 魔术态培育](https://blog.google/innovation-and-ai/models-and-research/quantum-computing/magic-state-cultivation-quantum-computing/)，留意从 color code 嫁接到 surface code 的那段。
- 想在自己领域复刻的人，读 [Athanor](https://arxiv.org/abs/2610.21055) 里关于冻结评测和 held-out 集的设计，这是防止 agent 刷分的关键。

## X 动态

### 主线：OpenCode 泄露用户 API key，蒸馏攻击开始直接花开发者的钱

蒸馏之争第一次让普通开发者直接蒙受损失。蒸馏指的是用强模型的输出去训练别的模型，上期 Anthropic 公开的反蒸馏防线讲的是模型厂商怎么防。这次是攻击者偷走用户存在第三方工具里的 key，用受害者的额度去调前沿模型、收集输出。10 月 18 日 02:08（Asia/Singapore），开源编码工具 OpenCode 在 [X 上披露](https://x.com/opencode/status/2111519637049319818)：一个「正在下线的旧系统」Console 被入侵，约 1.4% 的 Console 用户在工作区里存的 OpenAI、Anthropic、Google key 可能泄露。官方把事件定性为大规模蒸馏攻击，这是 OpenCode 自己的说法，攻击者身份目前没有公开证据。

影响范围比较具体。只有在 Console 工作区里存过第三方 provider key 的用户受影响，官方已经发了标题为「Action Required: Potential provider key breach」的通知邮件，没收到邮件就是没受影响。OpenCode 联合创始人称，普通 OpenCode 客户端里配置的 key 不经过公司服务器。Google AI Studio 负责人 [表示](https://x.com/EvanOtero/status/2111591525876474100) 已经封禁泄露的 Gemini key；据报道 Anthropic 也吊销了受影响的 Claude key。有用户自称被扣了几百美元，受影响的具体人数和金额都还没有核实，事件仍在处理中。

这件事暴露的是聚合类工具的结构性风险，就像把几家银行的卡都交给同一个代管人，代管人一出事，几张卡同时有风险。被盗 key 的调用直接打到模型厂商，OpenCode 的用量报表里看不到，只能去 OpenAI、Anthropic、Google 各自的后台查账单。时间点也有关联：上周 Anthropic 收紧了自家 API 的反蒸馏规则，前门难走了，压力就转到中转站、聚合工具这些中间商身上。用中转站或「一个 key 调多家模型」服务的中文开发者，处境和这次的受害者是一样的。

对开发者来说，这次的教训比事故本身更有用。第一，能在客户端本地配置的 key，就不要交给托管服务保存。第二，给每个工具单独开 key，设好用量上限和告警，出事时能单独吊销，不会牵连其他工具。第三，定期去各家控制台核对用量，不要只看第三方工具里的报表。团队负责人可以借这个机会盘点一下：组里有多少 key 存在第三方服务里，哪些已经很久没轮换了。

**深入学习建议**

- 先看 [OpenCode 官方披露](https://x.com/opencode/status/2111519637049319818)，再读 [The Latent 的报道](https://thelatent.co/models/opencode-says-breach-tied-to-distillation-attack-exposed-users-ai-provider-keys) 和 [Notebookcheck 的报道](https://www.notebookcheck.net/OpenCode-hacked-users-urged-to-revoke-their-API-keys.1426957.0.html) 了解时间线。
- 用过 OpenCode Console 的人：立刻在 OpenAI、Anthropic、Google 后台轮换 key、查看近两周的账单。
- 回看 [Anthropic 的反蒸馏防线](https://www.anthropic.com/research/distillation-defenses)，理解为什么压力会从厂商转到中间商。

### 主线：中国拟把大模型和智能体写进出口管制目录，开源豁免，闭源出海要重新算

中国第一次把大模型、智能体写进技术出口管制目录。目前还是征求意见稿，但企业现在就得开始准备。商务部、科技部 10 月 16 日发布 2026 年第 48 号 [公告](https://www.mofcom.gov.cn/zfxxgk/gkml/art/2026/art_ccd0391072a94c809ae7e820abe2536b.html)，拟在《中国禁止出口限制出口技术目录》中新增 40 项技术：AI 23 项（覆盖大模型、智能体、算力集群、信息处理），生物医药 5 项，光伏 12 项。意见征集到 11 月 15 日，同时即日起实施出口前登记。

所谓「技术出口」，比很多人想的要宽。登记范围包括三类：把技术所有权转让给境外、授权境外主体使用，以及技术所有权人或实际控制人变成境外主体。第三类最容易被忽视，它意味着并购、融资、搭境外控股架构这些资本动作本身也可能触发登记，不只是卖技术。对「国内研发团队 + 境外主体」架构的出海公司，以及准备引入海外投资的团队，这是要马上和法务对一遍的事。

开源和已公开发表的技术明确不在范围内。把权重以开源方式发布、把方法写成论文公开发表，原则上不受这份目录约束，这对国内开源模型生态是个重要信号，影响主要落在闭源技术的转让和授权上。另据路透报道，提案保留了通过 API 或 SaaS 向海外提供服务的空间，即海外客户调用你的模型服务不等于技术出口；这一条要以最终文本为准。

细节还有不少没核实。多方转述称目录分为「禁止 14 项、限制 26 项」，禁止类包括 AI 驱动的恶意代码生成，限制类包括 AI 辅助漏洞挖掘、用国内核心数据训练的大模型等。还有转述提到某个参数规模门槛。这些说法本期都没有逐条对照附件核实，引用时应以商务部原文附件为准。

放在更大的背景下看，过去几年的出口管制讨论主要是美国限制芯片和模型权重出口。这次中国从技术出口这一侧建立了自己的管理清单，中美两边都在给 AI 能力的跨境流动设门槛。对普通开发者，日常用开源模型、发论文基本不受影响；对创业公司和投资人，境外架构、技术授权协议和并购条款都要把这份目录算进去。

**深入学习建议**

- 必读 [商务部第 48 号公告原文](https://www.mofcom.gov.cn/zfxxgk/gkml/art/2026/art_ccd0391072a94c809ae7e820abe2536b.html) 和附件 1，逐条看 23 项 AI 技术的描述和控制要点。
- 有出海或境外架构的团队，对照登记的三类情形，和法务确认现有协议和股权结构是否需要登记。
- 想提意见的机构，留意 11 月 15 日的截止时间。

## 模型相关

### 主线：三天四个大号开放权重：美国模型集中入场，但分数还没追上中国头部，许可证差别更大

本窗口开放权重的密度是今年少见的，而且主角是美国公司。上期写 Meta 的 Muse Wonder 不放权重，这次 Meta 换了一款模型来做开放：官方账号 10 月 16 日 01:08（Asia/Singapore）宣布的 [Muse Spark Open](https://research.meta.ai/blog/muse-spark-open)。随后 Reflection 放出首个模型 Beam，NVIDIA 正式发布 Nemotron 3.5 系列，DeepSeek 也更新了 V4.1-Flash。选型时要看三件事：分数、许可证、硬件门槛，三者往往不在同一个模型上。

Muse Spark Open 是这一批里规模最大的。按 [HF 模型卡](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B)，它是原生多模态的 MoE（混合专家：每个 token 只激活一部分参数，像大医院里每个病人只看几个科），总参 816B，每 token 激活 42B，256 个专家里每次选 8 个，上下文 1M，提供 BF16 和 NVFP4（NVIDIA 的 4 位浮点格式）两种权重。NVFP4 版可以在两台 512GB 内存的 M5 Ultra Mac Studio 上用 MLX 跑。Meta 自称这是「迄今最强的美国开放权重模型」。[Artificial Analysis](https://artificialanalysis.ai/) 的智能指数给了 38.9，确实是美国开放权重里最高，但中国头部开源模型更高：MiMo-V2.6-Pro 46.3，GLM-5.3 44.8，Kimi K3 43.6。所以「美国开源追上中国」这个说法，按第三方分数看还不成立。许可证是另一道门槛：Muse Model License 要求界面显示「Built with Muse Spark Open」，年收入超过 2,000 万美元的模型服务商需要另签协议（据 VentureBeat），比 Apache 2.0 紧得多。

Reflection 的 [Beam 1.0](https://huggingface.co/reflection/Beam-1.0-501B-A23B) 是这一批里许可最宽的：Apache 2.0，总参 501B，激活约 23B，纯文本，上下文 1M，带 BF16、FP8、NVFP4 三种精度和一个 DFlash2 投机解码草稿模型。[Artificial Analysis 评测](https://artificialanalysis.ai/articles/reflection-beam) 给出 30.3 分，结论是 token 用量省，但幻觉率高达 47%，Terminal-Bench 4.0 只有 3.0%。厂商卡面上自述的 SWE-bench Verified 81.6%、Terminal Bench v2.1 80.1% 和第三方结果差距很大，基准版本也不同，技术报告还没出，这些自报数字暂时不要直接引用。NVIDIA 的 [Nemotron 3.5 Super VL](https://blogs.nvidia.com/blog/nemotron-3-5-super-vl/) 是 120B 总参、12B 激活的视觉语言模型，结构混合了 Mamba-2、MoE 和 attention，Artificial Analysis 评分 26.5。端侧的 Bolt 74B-A9B 用原生 2-bit 量化感知训练，打包后 24GB，目标是一张 24GB 显卡跑本地 agent；4GB 的 Bolt E4B 官方称将于 10 月 23 日上线。两款都用允许商用的 OpenMDW-1.1 许可，NVIDIA 还开放了数据集和训练配方。

DeepSeek 的回应是压价，再加一个新业务。10 月 17 日上线的 [V4.1-Flash-1017](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017) 是一套完整的新权重，MIT 许可，HF 显示约 763B 参数（有媒体写成 552B 主干加 196B Engram，口径不一）。API 模型名仍是 `deepseek-flash`，老用户会被自动切到新版。官方自述 DeepSWE v1.1 从 74.2 升到 77.0，Terminal-Bench 4.0 从 31.2 升到 42.3，每个任务成本不到 0.2 美元（上一版约 0.5 美元）。但官方选的对比对象是上一代的 Opus 5 和 GPT-5.6 Sol，HLE（无工具）42.6 也明显落后 Opus 5 的 56.3，独立评测还没出来。更值得注意的是 DeepSeek 第一次把自建搜索引擎单独拿出来卖：Search 和 Fetch API 每千次成功请求 0.75 美元，各 5 QPS，主打过滤 SEO 垃圾内容。通过 Claude Code、Codex 等走服务端工具的调用在 11 月 1 日前免费，等于把「模型 + 联网」打包卖给 agent 开发者。

工具链跟得很快。[llama.cpp v0.7.0](https://github.com/ggml-org/llama.cpp/releases/tag/v0.7.0) 新增 `--moe-cache-mib`：专家权重放在内存里时，用 LRU 缓存把常用专家搬到 GPU 上，官方称解码最高快约 2.2 倍，显存不够又想跑大 MoE 的人最该先试。注意它的 server 默认端口改成了 9931。[Transformers v5.20.0](https://github.com/huggingface/transformers/releases/tag/v5.20.0) 已经收录 Muse Spark Open；[Axolotl v0.21.0](https://github.com/axolotl-ai-cloud/axolotl/releases/tag/v0.21.0) 支持在单台 8×H200 上用 QLoRA 微调 Beam。

选型可以这样分：要宽松许可、自己再训练，看 Beam；只有一张 24GB 显卡跑本地 agent，看 Bolt；要便宜的编码 agent 和联网能力，看 DeepSeek，但先用自己的任务复测；Muse Spark Open 能力最强，商用前务必读完许可证。

**深入学习建议**

- 先读 [Muse Spark Open 博客](https://research.meta.ai/blog/muse-spark-open) 和 [HF 模型卡](https://huggingface.co/meta-models/Muse-Spark-Open-816B-A42B) 里的许可条款，再读 [HF 的 Beam 博客](https://huggingface.co/blog/reflection-beam)，它对架构和 SFT、RL 配方写得最细。
- 对照 [Artificial Analysis 的 Beam 评测](https://artificialanalysis.ai/articles/reflection-beam) 和 [Nemotron 3.5 评测](https://artificialanalysis.ai/articles/nemotron-3-5-super-and-bolt)，自己做一张「分数 × 许可 × 显存」的表。
- DeepSeek 用户读 [官方更新公告](https://api-docs.deepseek.com/news/news261017/)，确认自动切换对现有任务的影响，再看搜索 API 的计费细则。
- 本地部署的人升级 llama.cpp v0.7.0，试一下 `--moe-cache-mib`。

## 次要动态

**大厂与产业**

- **Claude Code 团队公开代码审查做法**：官方称 Claude 写了 Claude Code 约 90% 的代码，6–9 月合并的 PR 翻了一倍多，需要回滚的比例下降超过 40%（官方自报）。做法是多层 AI 审查，只有计费、自动更新、CI 等高风险改动必须由人看，人看的是测试输出、截图这类证据，而不是逐行读代码。同期 Code Review 面向 Team / Enterprise 正式可用；Opus 5.5 快速模式正式开放，官方称最高提速 2.5 倍，价格 8/40 美元，是标准价的两倍。
- **Anthropic 内部就业数据**：技术部门初级员工占比从 21% 降到 14%，初级技术岗招聘占比从 27% 降到 9%；8 月 agent 工时是员工的 6 倍。问卷里，91% 的员工预期 2030 年前会出现诺奖级 AI 发现，美国成年人只有 39%（均为官方自报）。
- **METR 进驻 Anthropic**：6 名 METR 人员获得接近员工级的内部访问权限，可以独立发布风险评估，Anthropic 没有否决权，只能按预设类别（如客户数据、模型架构）要求删改；另与 SecureBio、Accenture 合作评估。
- **Claude 解开 NIST 椭圆曲线种子之谜**：Anthropic 称内部研究模型不到 30 分钟查明，P-192 到 P-521 五条曲线的种子来自用时间戳初始化的普通伪随机数生成器。官方明确说这不是漏洞，反而降低了「后门」的嫌疑。
- **Anthropic IPO 估值预期下调（报道）**：路透援引消息人士称，部分投资者讨论把 11 月 IPO 的估值从约 2 万亿美元下调到约 1.5 万亿美元，Anthropic 没有确认。Replit CEO 澄清公司仍然模型中立，但首选合作伙伴已改为 OpenAI。
- **Claude Fable 5.5 传闻**：Azure 目录里出现了条目，Cursor 3.25.6 为这个模型名加了特判，Anthropic 没有表态，按传闻看待。
- **OpenAI**：ChatGPT 里的 GPT-6 Pro 和 GPT-6 Astra Pro 升级，支持多 agent 并行分工；GPT-Live-1.1 新增多种语言音色；GPT-Rosalind 推出面向美国高校实验室的学术计划。Codex 窗口内又做了两次全局额度重置，并通过子 agent 复用上下文、提高缓存命中率来提升「有效用量」（官方没有给出数字）。
- **OpenAI 和 Anthropic 各出 500 万美元**，资助 Simons 基金会的数学与 AI 计划。
- **Microsoft Research Magnetar**：通用 zkVM（零知识虚拟机，能证明一段程序被正确执行而不暴露输入），可以直接证明 Rust、Go、C 程序，官方称在 15 个基准上平均比现有最快系统快 10–39 倍，验证约 12 毫秒。
- **Google Research VERID**：让 agent 驱动真实的实验机器人完成闭环分子设计，官方称得到了单位数纳摩尔级的蛋白结合物。
- **Gemini 4 Argon 后续**：没有新模型或价格变化；DeepMind 演示 4 个 Argon agent 只靠代码和文本，27 小时打败 Minecraft 末影龙。

**开源**

- **OpenAI Codex CLI 0.163.0**：Codex 回复时可以随时插话纠偏，只读工具可以并行执行，新增可搜索的 `/config` 设置页。
- **腾讯混元 Hy-Memory**：开源的 agent 长期记忆引擎和 Python SDK（`hy-memory`），配套的 MemHub 可以统一管理 Claude Code、Cursor、Codex 的对话记录、跨应用召回；同时开源记忆专用模型 Hy-Memory-30B-A3B（约 3B 激活，Apache 2.0）。
- **chenglou/handwired**：把普通 JS 程序「编译」成无需训练、结果精确、完全可微的神经网络，适合用来理解程序和神经网络之间的等价关系。
- **REA 涨到约 30.6 万 star**，Perplexity Computer 把它集成为一项技能（细节来自第三方站点）。木马仿冒包的提醒仍然有效。

**模型**

- **FLUX 3 Image Klein**：BFL 的 5.6B 开放权重图像模型，支持文生图、编辑、最多 10 张参考图，原生 4K；官方要求前面接一个提示词扩写器（9B 的 klein-pup，Apache 2.0）。许可证是 FLUX Kommunity License，商用条款要另外核对。
- **NVIDIA Nemotron-Labs Dory1.0-4B**：循环结构的小模型，同一份权重可以选择循环 1、2 或 4 次，用推理算力换精度，前 4.5T token 直接用 NVFP4 预训练。卡面分数是自测，vLLM 和 llama.cpp 的支持还没合并。

**论文**

- [2610.22019](https://arxiv.org/abs/2610.22019)（NVIDIA）：公开 agent 后训练前的 midtraining 配方，自述在相同 SFT 下 SWE-bench Verified 从 60.7 升到 64.5，可以和 Nemotron 3.5 一起读。
- [2610.20941](https://arxiv.org/abs/2610.20941)（Redwood Research）：改写真实 agent 轨迹做红队，得到 35 个绕过监控的反例，其中 6 个也绕过了一家前沿开发者的监控器。只看动作的 agent 监控仍然脆弱。
- [2610.20667](https://arxiv.org/abs/2610.20667)（LASR Labs、UK AISI 等）：基准饱和后，用两两比较做对的轨迹来继续评估能力，自述预测误差比只看饱和分数低 5.3 倍。
